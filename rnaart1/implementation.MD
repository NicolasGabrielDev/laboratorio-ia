Ideal general-purpose prompt:

Complete the assignment described in the `.docx` file located in this directory.

Before implementing, read the `.docx` instructions and identify:
- the objective of the assignment;
- the training data;
- the test, validation, or classification data;
- the mandatory algorithm parameters;
- the questions that must be answered in the final result.

Use other project directories only as a reference for structure and patterns, without copying unnecessary code.

Extract the assignment data into separate `.json` files, for example:
- `training_data.json` for training data;
- `test_data.json` or `validation_data.json` for test or validation data;
- result files in `.json`, such as `training_results.json`, `classification_results.json`, or `validation_results.json`.

Create a single main Python file capable of running the entire assignment flow:
- load or build the extracted data;
- save the data as JSON;
- implement the algorithm requested in the assignment;
- train, test, validate, or classify as required;
- save all results as JSON;
- generate images, tables, or charts using only libraries available in `requirements.txt`;
- also generate a JavaScript data file, for example `results_data.js`, containing the already computed results for the HTML page to consume.

The Python file must not generate the contents of `index.html`.

The `index.html` file must be a separate static file, responsible only for presenting the answers and results. It must consume the data generated by Python through a local JavaScript file, such as `results_data.js`, using `<script src="results_data.js"></script>`. Do not use `fetch` to load JSON, so the HTML works when opened directly in the browser.

The HTML must include:
- a summary of the configuration used;
- final results;
- classification, test, or validation tables;
- generated images or charts;
- textual answers to the questions from the assignment.

Keep the implementation simple, educational, and compatible with the existing project pattern.

Add comments in Portuguese to the Python file explaining the key concepts of the subject and the algorithm, especially formulas, decision criteria, training, error, validation, and classification. Avoid obvious comments about syntax.

At the end, run the Python file and validate:
- whether the generated JSON files are valid;
- whether the expected results appear in the files;
- whether the images were generated;
- whether `index.html` consumes the generated data and displays the answers.
