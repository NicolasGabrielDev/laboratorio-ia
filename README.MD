# Artificial Intelligence Laboratory

Repository with practical implementations of classic neural networks developed for the Artificial Intelligence Laboratory course at CEFET-MG. The project brings together supervised, unsupervised, and associative experiments, with Python scripts, structured JSON data, analysis charts, and HTML pages for presenting results.

## What This Project Demonstrates

- Manual implementation of classic neural network algorithms.
- Preparation and structuring of training, test, and validation data.
- Training, classification, validation, and error analysis.
- Chart and table generation with `numpy` and `matplotlib`.
- Result organization in JSON for inspection and reuse.
- Static HTML pages for clear result communication.
- Ability to explain technical concepts through commented code, visualizations, and written answers.

## Experiments

| Directory | Topic | Main content |
|---|---|---|
| `perceptron/` | Simple Perceptron | Binary classification, multiple training runs, epoch analysis, and limitations on non-linearly separable problems. |
| `adaline/` | ADALINE | Delta Rule, MSE minimization, comparison between training runs, and sample classification. |
| `pmc1/` | Multilayer Perceptron | MLP with backpropagation for continuous output estimation, validation, and best configuration selection. |
| `pmc2/` | Multilayer Perceptron | Data extraction, training, validation, charts, and HTML result page. |
| `pmc3/` | MLP with TDNN | Financial time series forecasting using temporal windows and topology comparison. |
| `rbf1/` | RBF Network | Clustering, output layer weights, validation, and strategy analysis. |
| `rbf2/` | RBF Network | Training and validation with assignment data, JSON results, and charts. |
| `kohonen/` | Self-Organizing Map | 4x4 SOM, best matching unit, grouping by dominant class, and sample classification. |
| `hopfield/` | Hopfield Network | Associative memory, noisy pattern recovery, network energy, and robustness experiments. |
| `rnalvq1/` | LVQ-1 | Electric power profile classification using class prototypes. |
| `rnaart1/` | ART-1 | Incremental grouping of binary vectors with different vigilance parameters. |

## Standard Structure

The folders were organized around a simple and traceable pattern:

- `.docx` file with the original assignment;
- main Python script implementing the algorithm;
- `.json` files with data and results;
- `results_data.js` as a local data manifest for HTML pages;
- `.png` images with charts, tables, or visual explanations;
- `index.html` or `README.md` presenting the answers.

HTML pages consume local data through `<script src="results_data.js"></script>` when dynamic content is needed, avoiding any dependency on a local server or `fetch`.

## How To Run

Create and activate a virtual environment, install dependencies, and run the script from the desired folder:

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Examples:

```bash
python3 rnalvq1/lvq1.py
python3 rnaart1/art1.py
python3 kohonen/kohonen.py
python3 hopfield/hopfield.py
```

Some scripts were written to be executed from inside their own folder, especially older ones. If an input file is not found, run the command from the corresponding directory:

```bash
cd kohonen
python3 kohonen.py
```

After execution, open the folder's `index.html` when available. In the most recent modules, the page consumes the data generated by the Python script itself.
